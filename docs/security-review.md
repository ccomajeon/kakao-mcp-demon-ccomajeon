# AI 기능 범위 및 보안 검사 — 2026-11-01

대상: `kakao-mcp-ccomajeon@0.2.0-rebuild.2`. 이 문서는 애플리케이션 소스와 격리 재현 테스트에 대한 결과이며 실제 계정·운영 서버·카카오 서비스의 침투 시험은 아니다.

## AI에게 노출되는 범위

기본 16개 MCP 도구는 상태·대화방·친구·권한 조회, 대화 읽기·검색·대기·미리보기, 첨부 다운로드, 메시지·사진·파일 전송, 본인 메시지 수정·삭제, 권한 요청·철회, pause, 승인 대기, 작업 상태 확인이다.

선택 그룹 `chats` 10개, `friends` 8개, `events` 2개, `vault` 5개를 켜면 총 41개다. 방·친구·프로필 변경, 읽음 표시, 이벤트 처리, 대화 내보내기·링크/일정/할 일 정리가 추가된다. 정확한 명칭은 [README의 MCP 도구 목록](../README.md#mcp-도구-목록)을 참조한다.

- **ask:** 읽기와 발신은 별도 허가. 일회성 읽기 기본 20개·1회·10분. 방 전송 허가를 주면 이후 문구는 다시 승인하지 않고 전송할 수 있으며 기본 하루 50회 한도다. “이 문장만 허용”하는 문구별 제한은 아니다.
- **trust:** 규칙 없는 방의 읽기·발신, 전달·이모티콘·수정·삭제·프로필 변경·읽음·방 나가기/정보 변경·차단/해제·친구 추가에 개별 승인을 생략한다. 전송 일일 상한은 명시하지 않으면 없다. 친구 추가 기본 하루 10회, 속도 제한과 운영자 방 상한은 유지된다. 방 생성·권한 확대·pause 해제는 여전히 사람 승인이 필요하다.
- **나와의 채팅:** 기본 읽기·발신·본인 메시지 수정/삭제에 별도 확인이 없다. 저장된 읽기 규칙 및 상한은 우선한다.
- **pause:** 발신/변경 중지다. 모든 조회·메타데이터·수신 저장의 중지로 간주하면 안 된다.
- **방 상한:** 수정본에서는 본문 열람과 발신에 적용한다. 친구·대화방 메타데이터 목록을 비공개 처리하거나 수신 데이터의 로컬 저장을 중지하는 기능은 아니다.
- **별도 기능:** AI 모델, 상시 작업 스케줄러, 캘린더 등록, 서버 셸·임의 파일 접근은 이 MCP가 제공하지 않는다. 다른 도구를 연결하면 해당 권한은 이 서버의 통제 밖이다. 일정 후보 추출 도구는 규칙 기반 데이터 변환이며 모델 수준의 일정 판단을 보장하지 않는다.

## 남는 설계상 경계

1. **MCP 확인 창은 사람 인증 자체가 아니다.** 클라이언트가 실제 사람에게 질문한다는 신뢰가 필요하다. 같은 데몬에 접근 가능한 셸/SSH를 AI에게 주면 AI가 MCP 클라이언트처럼 응답할 수 있다. 사람 승인을 분리하려면 패스키를 먼저 등록·확인하고 `KAKAO_APPROVAL_CLIENT_CONFIRM=off`를 사용한다.
2. **OS 권한이 더 강하다.** 계정 정보와 SQLite 데이터는 파일 권한으로 보호되고 암호화 저장 보장을 제공하지 않는다. 서비스 사용자/root 또는 같은 계정으로 실행하는 AI는 파일 권한 경계를 공유한다. 패스키만으로 해당 OS 계정의 파일 접근을 차단하지 않는다.
3. **다중 사용자 호스트.** Linux는 MCP peer UID를 제한한다. macOS/Windows의 TCP에서는 동등한 OS 사용자 검증이 없어 같은 컴퓨터의 다른 사용자도 접근할 수 있다. macOS는 소유자 전용 디렉터리의 Unix socket을, Windows는 신뢰할 수 있는 전용 환경을 사용한다.
4. **프롬프트 인젝션.** 도구 결과에는 untrusted 표시와 승인 방어가 있지만 모델이 악성 대화를 무시한다고 증명하지 않는다. 읽을 수 있는 방과 보낼 수 있는 방이 넓으면 AI가 다른 방의 정보를 옮길 수 있다. 최소한의 그룹·방·일일 한도만 허용한다.
5. **외부 AI 데이터 처리.** 읽기 결과는 AI 클라이언트로 전달된다. 외부 모델에 전달되는 데이터는 해당 클라이언트·제공자의 정책에 따른다.
6. **감사 로그 한계.** `SendPolicy.audit`는 로그 쓰기 실패를 stderr 경고로 알리고 작업 자체를 차단하지 않는다. 누락 없는 규제·감사 기록을 보장하는 구조로 취급하지 않는다.

## 권장 운영 기본값

`ask` 유지, 필요한 MCP 그룹만 활성화, `KAKAO_ROOM_CEILING`에 사용할 방만 지정, `KAKAO_RECIPIENT_DAILY_LIMIT` 명시, 별도 서비스 사용자, MCP/웹 포트 외부 공개 금지 및 SSH 연결을 권장한다. 이번 검사에서 실제 사용자 설정·운영 모드·권한을 변경하지 않았다.
